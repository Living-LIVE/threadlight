# Support

Use GitHub Issues for reproducible bugs and feature proposals. Use GitHub Discussions, when
enabled, for setup questions, deployment patterns, and ideas that are not ready to become issues.

Before asking for help, include the Threadlight version or commit, operating system, Node.js or
Docker version, the relevant redacted configuration state, and the exact command or action that
failed. Never include provider keys, Discord tokens, raw private messages, or exported local
configuration files.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) rather than opening a public
issue.
